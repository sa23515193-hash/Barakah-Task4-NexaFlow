# NexaFlow — Multi-Page SaaS Website

A modern, responsive SaaS website built with React, React Router v6 and Tailwind CSS. This project demonstrates reusable UI components, client-side routing and a consistent multi-page user experience.

## Features

- Responsive SaaS landing page
- Reusable React components
- Client-side navigation with React Router v6
- Multiple pages and custom 404 page
- Modern UI and responsive layouts
- Tailwind CSS styling
- Frontend-only architecture
- GitHub Pages deployment support

## Tech Stack

- React
- JavaScript
- React Router DOM v6
- Tailwind CSS
- Vite

## Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

bash
npm install
npm run dev


Open the local URL displayed in your terminal.

### Production Build

bash
npm run build
npm run preview


## Deployment

This project is designed for static hosting. It can be deployed to GitHub Pages or another static hosting platform. Configure the correct Vite base path and router fallback behavior for the selected hosting platform.

## Project Type

Frontend-only React application. No backend server or database is required.
